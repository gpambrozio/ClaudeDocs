# Ultraplan is no longer available

Anthropic has removed the Ultraplan research preview. Research previews are experimental and may change or be removed based on feedback. The removal covers:

- The `/ultraplan` command
- The `ultraplan` keyword trigger
- The **No, refine with Ultraplan on Claude Code on the web** option in the plan approval dialog

For planning workflows, use:

- [Plan mode](permission-modes.md): in your local session, have Claude research your codebase and present a plan for your approval before it makes any changes
- [Claude Code on the web](claude-code-on-the-web.md): run Claude Code sessions on Anthropic’s cloud infrastructure and review changes in your browser
